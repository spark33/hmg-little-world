# ROAMY 공모전 기획서 — 미서명 검토용 초안

검토 기준일: 2026-11-15 KST. **제출 완료 문서가 아니다.** 공식 접수양식의 프로젝트 소개 1–8 순서를 따른다. 사용자가 선택한 운영용 기본정보는 개인 1인·일반(스타트업 포함) 부문이며, 운영용 이름은 별도 DOCX의 기본정보에만 반영했다. 연락처·구성원 상세·개별 동의·서명·서명일은 참가자가 비공개로 직접 작성해야 한다. 운영 접수번호와 확인되지 않은 자격·실적은 입력하지 않았다.

앱명 / 프로젝트명: **ROAMY — a little Seoul to keep**

## 1. 앱 한 줄 소개

ROAMY는 정차 후 서울의 경험을 나만의 작은 도시로 모아 보는 차량용 추억 컬렉션 앱의 프로토타입이며, 현재는 실제 방문을 인증하지 않는 서울 테마 데모를 제공한다.

## 2. 기획 배경

차량을 함께 이용하는 사람은 이동 중 나눈 대화와 목적지에서의 경험을 공유하지만, 이동이 끝난 뒤 그 경험을 가볍게 돌아보고 다음 나들이를 함께 고르는 과정은 여러 앱과 사진첩에 흩어져 있다. ROAMY는 반복 방문을 점수 경쟁으로 바꾸기보다, “어디를 함께 다녀왔고 다음에는 무엇을 해 보고 싶은가”를 작은 도시의 모습으로 보여 주려 한다.

초기 대상은 서울 근교 나들이를 함께 계획하는 운전자·동승자, 가족과 친구이다. 고객의 실제 수요와 사용 빈도는 아직 검증하지 않았다. 현재 구현은 서울 테마의 명확히 표시된 데모이며, 실제 이동 이력·GPS 방문·상점 이용을 자동 수집하거나 증명하지 않는다.

## 3. 앱 주요 기능 및 차량 특화 요소

**구현한 데모:** 광장시장·남산·석촌호수·성수의 네 가지 예시 기억으로 시작하고, 망원시장·경복궁에서 영감을 얻은 누각·북한산·서울 박물관의 네 가지 새 기념물을 발견·확인·수집한다. 카테고리 탐색, 다음 경험 추천, 수집 완료 상태, 메모 편집, 명시적 취소, 중복 방지, 낮/저녁·음소거·모션 감소 설정이 있다. 일러스트 예시와 사용자가 확인한 데모 기억은 출처를 구분한다. 자동 지형 확장이 아니라 여덟 개의 정해진 자리를 채우는 구조이다.

**차량에서의 의도:** 이동을 계획하는 공유 화면과 도착 후의 회상을 연결하되, 게임·카메라 조작·추억 편집은 안전한 정차 맥락에서만 제공한다. 운전 상태를 속도·내비게이션 이벤트나 사용자 버튼으로 추정하지 않는다. Android 네이티브 가림막과 웹 콘텐츠 차단을 함께 적용한다. 플랫폼 상태가 불명확하거나 앱이 백그라운드로 전환되면 상호작용을 중지한다.

**현재 한계:** 실제 Pleos 실행 검증이 끝나지 않아 차량 빌드의 정차 허용 경로는 아직 잠겨 있다. 브라우저 개발 프리뷰가 이 안전 제한을 검증한 차량 화면인 것처럼 설명하지 않는다. 상점·거리·여행·방문 확인은 예시이며, 실제 서울 POI 공급자나 자동 방문 인증은 연결하지 않았다.

## 4. 주요 사용 시나리오

정차 후 사용자와 동승자가 작은 서울에서 광장시장 예시 기억을 열고 다음 망원시장 소풍을 살펴본다. 예시 목적지임을 확인한 뒤 데모 여행을 진행하고, 사용자가 “내 세계에 추가”를 직접 확인한 경우에만 기록을 남긴다. 새 기념물이 나타나며 다음 서울 경험을 선택할 수 있다. “아직 아니에요”에 해당하는 취소 동작은 기록을 추가하지 않는다.

확인된 데모 기록은 연출보다 먼저 기기 저장을 시도한다. 저장에 실패하면 해당 기록은 이번 세션에서만 유지되며, 화면에 세션 전용 경고를 표시한다. 저장에 성공한 기록은 안전 제한이나 앱 중단 후 다시 불러올 수 있으며, 연출을 운전 중 재생하지 않는다. 모션 감소를 선택하면 기념물을 즉시 보여 준다. 메모와 버전이 있는 백업을 수정·내보내기·복구할 수 있으며, 가져오기는 미리보기와 교체 확인을 거친다. 기존 Detroit/Chicago 데모 기록은 원래 이름과 날짜를 유지하는 별도 보관함에 남겨 서울 방문으로 바꾸지 않는다.

현재 클라우드 환경에는 필요한 KVM/가상화 CPU 기능과 지원 GPU가 노출되지 않아 공식 에뮬레이터 구동 증거가 없다. 클라우드에서 개발을 계속하며, 해당 인프라를 제공받은 뒤 콜드 부트·ADB 연결·설치·안전 전이·내비게이션·렌더링·로그 검증을 진행한다. 일반 Android 에뮬레이터나 브라우저를 Pleos 검증으로 대체하지 않는다. 현재 서명되지 않은 차량 release 산출물과 debug APK를 심사용 실행 가능한 release라고 기재하지 않는다.

브라우저 저장·백업·클립보드 내용은 평문이며 민감한 개인정보를 입력하도록 유도하지 않는다. 지원되지 않는 차량 기능과 미검증 성능은 완료 기능으로 표시하지 않는다.

## 6. 기대효과 및 발전 가능성

목표 가치는 정차 후 짧은 공동 회상과 다음 서울 나들이 계획을 연결하고, 흩어진 경험을 지속적으로 다시 보고 싶은 공간으로 바꾸는 것이다. 절차적으로 직접 만든 3D 기념물, 서울의 음식·자연·문화 경험을 연결하는 탐색, 점수 대신 사용자의 확인을 존중하는 수집 방식을 차별화 가설로 둔다. 이는 시장 전체에 전례가 없다는 검증된 주장이 아니다.

현재 실제 사용자 수, MAU, 리텐션, 유료 전환·제휴 매출 실적은 없다. 예상 MAU·Retention Rate도 아직 산정하지 않았다. 가설 검증은 동의한 소규모 사용자 테스트에서 첫 탐색/확인 완료율, 정차 중 과업 완료 시간, 재방문 이유, 기념물·메모 재열람 의도와 부담을 관찰하는 방식으로 시작한다. 수치 목표는 기준선 측정 후 정한다. 지속 이용이 확인된 경우에만 다른 지역의 기념물·동행자 경험·권리가 확보된 장소 제휴 등을 검토한다. 개인정보와 광고 부담을 늘리는 기능은 사전 검증 없이 도입하지 않는다.
