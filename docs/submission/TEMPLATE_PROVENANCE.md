The original was downloaded into the cloud scratch workspace and inspected as a DOCX ZIP/XML document. It contains applicant details, eight numbered project-introduction fields, privacy consent and a separate per-participant consent/signature table. The project narrative can expand beyond its initial text boxes; the form does not impose a narrative page limit. The [submission clarification notice](https://appdevchallenge.auto-hmg.io/notice/c0a1a000-2026-4923-8000-000000000007) permits DOCX/PDF and electronic or inserted-image signatures while retaining required content/order.

`ROAMY_application_unsigned.docx` is a **derived public planning draft**, not the original template and not a signed application. The user-authorized basic entrant label, declared individual/General category/count, non-private app name and eight project narrative cells were filled. The original legal consent text and all contact/member-detail, consent-choice, signature and signature-date fields were left unchanged/blank. The project narrative excludes the entrant's name. A visible draft banner and non-personal metadata were added. Do not represent its hash as the official template hash or treat the untouched consent text as consent by any participant.

No completed private form, contact details, actual signature, release credential or organizer submission is included in the repository. To apply, the owner must make a private final copy, confirm eligibility and the declared basic information, review the current rules, complete each required field and obtain their own dated consent/signature. Additional teammate CC is relevant only if the declared solo entry changes. Check the resulting DOCX/PDF, attachments, metadata and links before sending before the official deadline.
